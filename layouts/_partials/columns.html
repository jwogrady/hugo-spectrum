{{- /* How many columns this page has, decided in one place. Returns "one" or "two". baseof.html reads it and owns the spread, so no layout states its own frame. three reference pages — prose, its branch, and the subject field two journal index and tag results — records plus the subject field contact — the form plus its guidance a hierarchical page branch — content plus child navigation one plates, single entries, flat pages, hero, landing, conversion Posts are flat and dated, so an entry is one column. Pages nest, so a page inside a branch gets the branch's navigation beside it. Either way the container fills the frame, so the outer edges of the page are in the same place everywhere and nothing shifts on navigation. Written as explicit booleans rather than one `and`/`cond` chain: `and` short-circuits to false, and false is not nil, so testing the result against nil made every post claim a branch it did not have. A page can override with `columns = "one"` in front matter. Layouts that own their whole width say so here rather than in each page's front matter, so the frame stays one decision. hero and landing are one column even inside a branch — without this they inherited the branch's second column and rendered a 17rem hole beside a banner. */ -}} {{- with .Params.columns }}{{ return . }}{{ end -}} {{- if eq .Layout "reference" }}{{ return "three" }}{{ end -}} {{- if or (eq .Layout "hero") (eq .Layout "landing") (eq .Layout "conversion") }}{{ return "one" }}{{ end -}} {{- $two := false -}} {{- if or .IsHome (eq .Kind "term") (isset .Params "form") }}{{ $two = true }}{{ end -}} {{- with partial "branch-root.html" . }}{{ $two = true }}{{ end -}} {{- return cond $two "two" "one" -}}
