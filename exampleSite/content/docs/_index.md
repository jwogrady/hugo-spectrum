Pages nest; the journal does not. An entry is flat, dated and tagged, and the
index finds it. A document has parts that are read in order, so it is a branch:
this page is the introduction, and its three children hang beneath it.

The aside carries the branch — every page in it shows the same tree with itself
marked, so a child is never a dead end with only the breadcrumb for a way back.
Order comes from `weight` in front matter, not from the filename.
