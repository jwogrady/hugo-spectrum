# Bundled typefaces

All three are SIL Open Font License 1.1, which permits bundling and
redistribution. Latin subsets, variable axes.

| Family | Source | License |
|---|---|---|
| Source Serif 4 | Adobe | [OFL 1.1](https://github.com/adobe-fonts/source-serif/blob/release/LICENSE.md) |
| Public Sans | US Web Design System | [OFL 1.1](https://github.com/uswds/public-sans/blob/develop/LICENSE.md) |
| Source Code Pro | Adobe | [OFL 1.1](https://github.com/adobe-fonts/source-code-pro/blob/release/LICENSE.md) |

Subsetted via the Google Fonts CSS API and self-hosted so the theme makes no
third-party request at page load.
